# Advanced-Body-movers-Phisics-Control
Для просто лінійної швидкості використовується VectorForce, для зручності його треба вставити в середину об'єкту на який буде діяти сила, для нього потрібен лише 1 аттачмент,  також в залежності від ситуації можна налаштувати, на які осі орієнтуватись(на незмінні осі світу чи на динамічні осі аттачменту), швидкість по осях вказується  через Вектор3; 

Для руху навколо своєї осі використовується AngularVelocity, для нього також треба лише один аттачмент(швидкість повороту в рад/с також вказується через вектор), якщо величина швидкості буде від'ємною то крутка буде в напрямку год стрілки, якщо ж величина додатня то крутка буде проти год стрілки, повороти орієнтується так само як попередній метод;

Для магнітного притягування використовується LineForce, для нього треба два аттачменти де Нульовий повинен бути в об'єкті що пртягується, а інший в об'єкті що притягує, якщо сила притягання буде від'ємною то об'єкти будуть відштовхуватись. Кожен із вище зазначених методів краще робити в об'єктах до яких вони відносяться (окрім останнього, йогокраще ложити в об'єкт що притягується).
